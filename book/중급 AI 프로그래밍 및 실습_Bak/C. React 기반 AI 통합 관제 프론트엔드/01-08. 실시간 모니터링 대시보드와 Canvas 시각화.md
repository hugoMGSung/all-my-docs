
## 들어가며

앞 장에서는 React 상태 관리와 이미지 위 Bounding Box의 기본 원리를 익혔습니다. 이번 장에서는 이를 실제 화면 구성으로 확장해 **실시간 수산물 모니터링 대시보드**를 만듭니다.

대시보드에는 양식장 상태, 최근 관측 자료, AI 분석 결과를 배치합니다. 탐지 결과의 Bounding Box는 HTML 요소 대신 **Canvas API**로 이미지 위에 그려 봅니다. 마지막에는 일정한 간격으로 서버 자료를 다시 불러와 화면을 갱신합니다.

## 1. 대시보드에 필요한 정보 정하기

화면을 만들기 전에 사용자에게 필요한 정보를 정리합니다.

- 현재 모니터링 중인 양식장과 장비 상태
- 최근 수온 및 관측 시각
- AI가 탐지한 어종과 신뢰도
- 탐지된 객체의 이미지 내 위치
- 최근 관측 기록과 오류 상태

정보를 역할에 따라 컴포넌트로 나눕니다.

```text
Dashboard
├─ DashboardHeader
├─ StatusSummary
│  ├─ MetricCard (수온)
│  ├─ MetricCard (최근 관측 시각)
│  └─ MetricCard (탐지 개체 수)
├─ LiveObservationPanel
│  ├─ CanvasDetectionViewer
│  └─ DetectionList
└─ RecentObservations
```

컴포넌트로 나누면 화면을 수정하거나 다른 페이지에서 재사용하기 쉬워집니다.

## 2. 대시보드 응답 데이터 준비하기

프론트엔드가 표시할 자료의 예시는 다음과 같습니다.

```json
{
  "pond": {
    "pondId": "pond-01",
    "name": "1번 양식장",
    "status": "normal"
  },
  "latestObservation": {
    "observationId": "obs-001",
    "observedAt": "2026-12-01T01:30:00.000Z",
    "waterTemperature": 24.5,
    "imageUrl": "/uploads/obs-001.jpg",
    "detections": [
      {
        "label": "참돔",
        "confidence": 0.94,
        "box": { "x": 0.25, "y": 0.18, "width": 0.3, "height": 0.42 }

```

`detections`는 7일차에 정한 정규화 Bounding Box 형식을 사용합니다. 프론트엔드와 백엔드가 필드명이나 좌표 기준을 다르게 해석하지 않도록 API 계약을 공유해야 합니다.

## 4. 상태 요약 카드 만들기

반복되는 표시를 `MetricCard`로 만들어 수온, 최근 관측 시간, 탐지 개체 수에 재사용합니다.

```jsx
function MetricCard({ title, value, unit, description }) {
  return (
    <article className="rounded-xl border border-slate-200 bg-white p-4 shadow-sm">
      <p className="text-sm text-slate-500">{title}</p>
      <p className="mt-2 text-2xl font-semibold">
        {value}
        {unit && <span className="ml-1 text-base font-normal">{unit}</span>}
      </p>
      {description && <p className="mt-2 text-xs text-slate-500">{description}</p>}
    </article>
  );
}
```

카드 배열은 `map()`으로 표시할 수 있습니다.

```jsx
const metrics = [
  { title: "현재 수온", value: "24.5", unit: "℃", description: "최근 관측 기준" },
  { title: "탐지 개체", value: "12", unit: "마리", description: "최근 이미지 기준" },

function StatusSummary() {
  return (

```

실제 값은 상수 대신 API 응답에서 가져옵니다. 상태 값의 의미와 단위를 화면에 함께 표시하면 사용자가 값을 해석하기 쉽습니다.

## 5. Canvas API로 이미지 위에 객체 표시하기

Canvas API는 JavaScript로 선, 도형, 텍스트, 이미지를 하나의 캔버스에 그릴 수 있게 합니다. 객체 수가 많거나 프레임마다 표시를 갱신해야 할 때 Bounding Box를 Canvas에 직접 그릴 수 있습니다.

Canvas 좌표는 픽셀 기준입니다. API의 정규화 좌표를 이미지 표시 크기에 곱해 픽셀 좌표로 변환합니다.

```text
left(px)   = x × 표시 너비
 top(px)   = y × 표시 높이
width(px)  = width × 표시 너비
height(px) = height × 표시 높이
```

React에서 Canvas 요소를 다룰 때는 `useRef`로 실제 DOM 요소를 참조합니다.

```jsx
import { useEffect, useRef } from "react";

function CanvasDetectionViewer({ imageUrl, detections = [] }) {
  const imageRef = useRef(null);
  const canvasRef = useRef(null);

  useEffect(() => {
    const image = imageRef.current;
    const canvas = canvasRef.current;
    if (!image || !canvas) return;

    function drawDetections() {
      const width = image.clientWidth;
      const height = image.clientHeight;
      if (!width || !height) return;

      const pixelRatio = window.devicePixelRatio || 1;
      canvas.width = Math.round(width * pixelRatio);
      canvas.height = Math.round(height * pixelRatio);
      canvas.style.width = `${width}px`;
      canvas.style.height = `${height}px`;

      const context = canvas.getContext("2d");
      context.setTransform(pixelRatio, 0, 0, pixelRatio, 0, 0);
      context.clearRect(0, 0, width, height);
      context.lineWidth = 2;
      context.font = "14px sans-serif";

      for (const detection of detections) {
        const { x, y, width: boxWidth, height: boxHeight } = detection.box;
        const left = x * width;
        const top = y * height;
        const boxPixelWidth = boxWidth * width;
        const boxPixelHeight = boxHeight * height;
        const label = `${detection.label} ${(detection.confidence * 100).toFixed(1)}%`;

        context.strokeStyle = "#34d399";
        context.strokeRect(left, top, boxPixelWidth, boxPixelHeight);

        const labelWidth = context.measureText(label).width + 12;
        const labelTop = Math.max(0, top - 24);
        context.fillStyle = "#047857";
        context.fillRect(left, labelTop, labelWidth, 22);
        context.fillStyle = "#ffffff";
        context.fillText(label, left + 6, labelTop + 15);
      }
    }

    if (image.complete) {
      drawDetections();
    } else {
      image.addEventListener("load", drawDetections, { once: true });
    }

    const observer = new ResizeObserver(drawDetections);
    observer.observe(image);

    return () => {
      image.removeEventListener("load", drawDetections);
      observer.disconnect();
    };
  }, [imageUrl, detections]);

  return (
    <div className="relative inline-block max-w-full overflow-hidden rounded-lg bg-slate-900">
      <img
        ref={imageRef}
        src={imageUrl}
        alt="AI 분석 이미지"
        className="block max-h-[560px] max-w-full object-contain"
      />
      <canvas
        ref={canvasRef}
        aria-hidden="true"
        className="pointer-events-none absolute left-0 top-0"
      />
    </div>
  );
}
```

`getContext("2d")`는 2차원 그림 작업을 위한 Canvas 컨텍스트를 가져옵니다. `strokeRect()`는 경계 사각형을 그리고, `fillRect()`와 `fillText()`는 라벨 배경과 텍스트를 표시합니다.

Canvas의 실제 픽셀 크기는 CSS 표시 크기와 다를 수 있습니다. `devicePixelRatio`를 반영하면 고해상도 화면에서도 선과 글자가 선명하게 보입니다. `ResizeObserver`는 이미지 크기가 달라질 때 다시 그리도록 합니다.

## 6. 이미지 비율과 좌표 맞추기

Canvas 오버레이가 이미지와 같은 위치에 보이려면 이미지와 Canvas의 기준 영역이 같아야 합니다. 이미지의 실제 비율을 유지하면서 컨테이너 안에 맞출 때 `object-fit: contain`은 남는 여백을 만들 수 있습니다. 이때 Canvas를 컨테이너 전체에 그대로 맞추면 탐지 상자가 어긋날 수 있습니다.

정확한 구현에서는 다음 중 한 가지 방식을 택합니다.

- 이미지 크기에 맞춰 래퍼의 종횡비를 유지하고 이미지와 Canvas를 같은 크기로 배치합니다.
- 이미지가 실제로 그려진 콘텐츠 영역을 계산해 좌표 변환에 반영합니다.
- 서버에서 표시 이미지 기준으로 계산한 정규화 좌표를 전달합니다.

수업 예제는 이미지와 오버레이의 표시 영역이 같다는 전제로 단순화합니다. 브라우저 폭을 바꿔 상자 위치가 유지되는지 확인하고, 여백이 생기는 레이아웃에서는 보정이 필요함을 확인합니다.

## 7. 일정 간격으로 관측 자료 갱신하기

실시간에 가까운 대시보드는 일정 간격으로 최신 자료를 다시 요청할 수 있습니다. 이 방식은 폴링(Polling)이라고 합니다.

```jsx
import { useEffect, useState } from "react";

function useLatestObservation(refreshMs = 5000) {
  const [observation, setObservation] = useState(null);
  const [error, setError] = useState("");

  useEffect(() => {
    let cancelled = false;
    let timerId;

    async function refresh() {
      try {
        const response = await fetch(
          "http://localhost:3000/api/observations/latest"
        );
        if (!response.ok) {
          throw new Error("최신 관측 정보를 가져오지 못했습니다.");
        }

        const data = await response.json();
        if (!cancelled) {
          setObservation(data);
          setError("");
        }
      } catch (requestError) {
        if (!cancelled) setError(requestError.message);
      } finally {
        if (!cancelled) {
          timerId = window.setTimeout(refresh, refreshMs);
        }
      }
    }

    refresh();

    return () => {
      cancelled = true;
      window.clearTimeout(timerId);
    };
  }, [refreshMs]);

  return { observation, error };
}
```

요청이 끝난 뒤 다음 갱신 타이머를 설정하므로 요청이 겹치는 것을 줄일 수 있습니다. 컴포넌트가 화면에서 사라지면 타이머를 정리합니다. 서버에 `/api/observations/latest`가 아직 없다면 목록 API를 사용하거나 백엔드에 최신 관측 경로를 추가합니다.

폴링 간격이 짧을수록 정보가 자주 갱신되지만 서버 요청 수도 늘어납니다. 실제 운영에서는 사용자 수, 데이터 변경 빈도, 서버 용량을 고려해 간격을 정합니다. 더 즉각적인 양방향 실시간 통신이 필요하면 WebSocket이나 서버 전송 이벤트를 검토할 수 있습니다.

## 10. 접근성과 오류 상태 확인하기

대시보드는 상태 색상만으로 정상·주의를 구별하지 않습니다. 색상과 함께 텍스트, 아이콘, 설명을 제공해 색을 구분하기 어려운 사용자도 상태를 이해할 수 있게 합니다.

이미지에는 내용을 설명하는 `alt` 텍스트를 지정합니다. Canvas 자체는 화면 읽기 도구가 그린 내용을 자동으로 설명하지 않으므로, 탐지 결과 목록을 HTML 텍스트로 별도 제공하는 것이 좋습니다.

화면에서 다음 상태를 구분합니다.

- 데이터 로딩 중
- 최신 데이터를 정상적으로 불러온 상태
- 탐지 결과가 없는 상태
- 이미지 파일을 불러오지 못한 상태
- 서버 요청이 실패하거나 지연된 상태

## 핵심 정리

- 대시보드는 상태 요약, 최신 관측, AI 탐지 결과를 한 화면에 모읍니다.
- 컴포넌트를 역할별로 나누면 유지보수와 재사용이 쉬워집니다.
- Canvas API는 이미지 위에 Bounding Box와 라벨을 직접 그릴 수 있습니다.
- 정규화 좌표를 표시 크기에 맞춰 변환하고, 이미지와 Canvas의 기준 영역을 일치시켜야 합니다.
- 폴링은 일정 간격으로 서버를 다시 요청하는 실시간 갱신 방식입니다.
- Tailwind CSS로 반응형 UI를 구성하고 Chart.js를 시계열 차트 영역에 연결합니다.
- 다음 수업에서는 Chart.js로 해양 시계열 데이터 추이 차트를 구현합니다.
