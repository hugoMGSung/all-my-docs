
## 들어가며

앞 장에서는 추론 결과의 JSON 규격을 정리했습니다. 이번 장부터는 AI 결과를 사용자가 확인할 수 있도록 React 기반 프론트엔드를 만듭니다.

오늘은 React 컴포넌트와 상태 관리의 기본을 익히고, 이미지 안에서 AI가 찾은 객체 위치를 **Bounding Box(경계 상자)**로 표시합니다. 서버에서 받은 예측 결과를 화면의 상태로 관리하고, 상태가 바뀔 때 컴포넌트가 어떻게 다시 렌더링되는지도 살펴봅니다.

## 1. React 프론트엔드의 역할

React는 화면을 재사용 가능한 컴포넌트 단위로 구성하는 JavaScript 라이브러리입니다. 스마트 양식장 대시보드에서는 관측 이미지, 수온, AI 탐지 결과, 차트 등을 각각 컴포넌트로 나눌 수 있습니다.

```text
App
├─ Header
├─ ObservationSummary
├─ DetectionViewer
│  ├─ ObservationImage
│  └─ BoundingBox
└─ ObservationList
```

컴포넌트는 화면의 일부를 담당합니다. 각 컴포넌트는 전달받은 데이터와 자신의 상태를 바탕으로 화면을 표시합니다.

## 2. React 프로젝트 준비하기

Vite를 이용해 React 프로젝트를 준비할 수 있습니다. 이미 프론트엔드 프로젝트가 있다면 기존 프로젝트 폴더에서 이어서 작업합니다.

```bash
npm create vite@latest smart-aquaculture-web -- --template react
cd smart-aquaculture-web
npm install
npm run dev
```

개발 서버를 실행하면 터미널에 표시된 로컬 주소에서 React 페이지를 확인할 수 있습니다.

Tailwind CSS가 설정된 프로젝트에서는 유틸리티 클래스를 JSX의 `className`에 사용합니다. 아직 설정되지 않았다면 과정의 기본 프로젝트 설정을 따라 Tailwind CSS를 구성합니다.

```jsx
function PageTitle() {
  return (
    <h1 className="text-2xl font-bold text-slate-800">
      스마트 양식장 모니터링
    </h1>
  );
}
```

React에서는 HTML의 `class` 대신 `className`을 사용합니다. Tailwind CSS는 `flex`, `p-4`, `rounded-lg`처럼 작은 스타일 클래스를 조합해 레이아웃과 디자인을 구성합니다.

## 3. 함수 컴포넌트와 JSX

React 컴포넌트는 화면에 표시할 요소를 반환하는 함수입니다. JSX는 JavaScript 코드 안에서 HTML과 비슷한 표기를 사용하도록 해줍니다.

```jsx
function ObservationCard() {
  return (
    <article className="rounded-lg border bg-white p-4 shadow-sm">
      <h2 className="text-lg font-semibold">1번 양식장</h2>
      <p className="mt-2 text-slate-600">현재 수온: 24.5℃</p>
    </article>
  );
}

export default ObservationCard;
```

JSX에서 JavaScript 값을 사용하려면 중괄호를 씁니다. 컴포넌트 이름은 대문자로 시작해야 합니다. 여러 형제 요소를 반환할 때는 하나의 부모 요소나 Fragment로 감쌉니다.

## 4. Props와 State

Props는 부모 컴포넌트가 자식에게 전달하는 값입니다. State는 컴포넌트가 화면을 그리는 데 사용하는 변경 가능한 상태입니다.

```jsx
function TemperatureCard({ temperature }) {
  return (
    <div className="rounded-lg bg-sky-50 p-4">
      <p>수온</p>
      <strong>{temperature}℃</strong>
    </div>
  );
}
```

부모 컴포넌트는 `temperature`를 전달합니다.

```jsx
<TemperatureCard temperature={24.5} />
```

사용자 선택이나 서버 요청 결과처럼 컴포넌트가 관리해야 하는 값은 State로 둘 수 있습니다. State가 변경되면 React는 그 값을 사용하는 컴포넌트를 다시 렌더링합니다.

```jsx
import { useState } from "react";

function PondSelector() {
  const [selectedPond, setSelectedPond] = useState("pond-01");

  return (
    <label>
      양식장 선택
      <select
        value={selectedPond}
        onChange={(event) => setSelectedPond(event.target.value)}
      >
        <option value="pond-01">1번 양식장</option>
        <option value="pond-02">2번 양식장</option>
      </select>
    </label>
  );
}
```

State를 직접 수정하지 않고 `setSelectedPond()` 같은 상태 변경 함수를 사용합니다. React가 변경을 감지하고 화면을 다시 그릴 수 있기 때문입니다.

## 5. 컴포넌트 생명주기와 useEffect

컴포넌트는 화면에 나타나고, 상태가 바뀌어 다시 렌더링되고, 화면에서 사라질 수 있습니다. 이를 컴포넌트의 생명주기라고 설명합니다.

함수 컴포넌트에서는 `useEffect`를 사용해 렌더링과 연결된 부수 효과를 처리할 수 있습니다. 예를 들어 서버에서 데이터를 불러오거나 타이머를 등록할 때 사용합니다.

```jsx
import { useEffect, useState } from "react";

function ObservationCount() {
  const [count, setCount] = useState(null);

  useEffect(() => {
    let cancelled = false;

    async function loadCount() {
      const response = await fetch("http://localhost:3000/api/observations");
      const data = await response.json();

      if (!cancelled) {
        setCount(data.count);
      }
    }

    loadCount();

    return () => {
      cancelled = true;
    };
  }, []);

  if (count === null) {
    return <p>관측 데이터를 불러오는 중입니다.</p>;
  }

  return <p>관측 자료 {count}건</p>;
}
```

두 번째 인자로 빈 배열 `[]`을 전달하면 컴포넌트가 처음 화면에 나타날 때 효과를 실행합니다. 반환한 함수는 컴포넌트가 사라지거나 효과가 다시 실행되기 전에 정리 작업을 수행합니다.

실제 서비스에서는 네트워크 요청 실패와 로딩 상태를 별도로 관리해야 합니다. 다음 예제에서는 로딩·오류·결과 상태를 분리합니다.

```jsx
const [observations, setObservations] = useState([]);
const [loading, setLoading] = useState(true);
const [error, setError] = useState("");
```

상태를 구분하면 화면에 진행 중 표시, 오류 안내, 결과 목록을 각각 보여줄 수 있습니다.

## 6. 상태 변경에 따라 화면 표시하기

관측 데이터를 서버에서 받아 목록으로 표시하는 컴포넌트를 만듭니다.

```jsx
import { useEffect, useState } from "react";

function ObservationList() {
  const [items, setItems] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const controller = new AbortController();

    async function loadObservations() {
      try {
        const response = await fetch(
          "http://localhost:3000/api/observations",
          { signal: controller.signal }
        );

        if (!response.ok) {
          throw new Error("관측 데이터를 불러오지 못했습니다.");
        }

        const data = await response.json();
        setItems(data.items);
      } catch (requestError) {
        if (requestError.name !== "AbortError") {
          setError(requestError.message);
        }
      } finally {
        setLoading(false);
      }
    }

    loadObservations();
    return () => controller.abort();
  }, []);

  if (loading) return <p>불러오는 중...</p>;
  if (error) return <p className="text-red-700">{error}</p>;
  if (items.length === 0) return <p>관측 데이터가 없습니다.</p>;

  return (
    <ul className="space-y-3">
      {items.map((item) => (
        <li key={item._id} className="rounded border bg-white p-3">
          <strong>{item.species}</strong>
          <span className="ml-3">수온 {item.waterTemperature}℃</span>
        </li>
      ))}
    </ul>
  );
}
```

`map()`으로 배열을 화면 요소로 바꿉니다. 각 요소에는 고유한 `key`를 지정해야 React가 목록의 변경을 효율적으로 추적할 수 있습니다. API 서버와 다른 주소에서 프론트엔드를 실행할 경우 백엔드의 CORS 설정도 필요합니다.

## 7. Bounding Box란?

Bounding Box는 이미지에서 탐지된 객체를 둘러싸는 사각형입니다. AI 객체 탐지 결과에는 일반적으로 객체의 클래스, 신뢰도, 사각형의 위치와 크기가 포함됩니다.

픽셀 단위 좌표를 사용하면 이미지 크기가 달라질 때 좌표를 변환해야 합니다. 화면 크기가 달라도 같은 비율 위치에 상자를 표시하려면 0~1 사이의 정규화 좌표를 사용할 수 있습니다.

```json
{
  "label": "참돔",
  "confidence": 0.94,
  "box": {
    "x": 0.25,
    "y": 0.18,
    "width": 0.30,
    "height": 0.42
  }
}
```

이 문서에서는 `x`, `y`를 이미지 왼쪽 위 모서리 기준으로 정의합니다. `width`, `height`는 상자의 너비와 높이입니다. 모두 이미지 전체 크기에 대한 비율입니다.

예를 들어 `x = 0.25`는 상자 왼쪽이 이미지 너비의 25% 지점에 있음을 뜻합니다. 화면에 픽셀 좌표가 필요하면 이미지 표시 너비와 높이를 곱해 계산할 수 있습니다.

```text
left(px)   = x × 이미지 표시 너비
 top(px)   = y × 이미지 표시 높이
width(px)  = width × 이미지 표시 너비
height(px) = height × 이미지 표시 높이
```

## 8. 이미지 위에 Bounding Box 렌더링하기

이미지와 상자를 같은 부모 요소 안에 배치합니다. 부모를 `position: relative`로 설정하고, 상자를 `position: absolute`로 이미지 위에 겹칩니다.

```jsx
function DetectionViewer({ imageUrl, detections }) {
  return (
    <div className="relative inline-block max-w-full">
      <img
        src={imageUrl}
        alt="AI 분석 대상 이미지"
        className="block max-h-[560px] max-w-full object-contain"
      />

      {detections.map((item, index) => (
        <div
          key={`${item.label}-${index}`}
          className="absolute border-2 border-emerald-400"
          style={{
            left: `${item.box.x * 100}%`,
            top: `${item.box.y * 100}%`,
            width: `${item.box.width * 100}%`,
            height: `${item.box.height * 100}%`
          }}
        >
          <span className="absolute -top-6 left-0 whitespace-nowrap rounded bg-emerald-700 px-2 py-1 text-xs text-white">
            {item.label} {(item.confidence * 100).toFixed(1)}%
          </span>
        </div>
      ))}
    </div>
  );
}
```

상자 좌표를 퍼센트로 설정하면 이미지 크기가 바뀌어도 비율에 맞춰 표시할 수 있습니다. 상자 위치를 계산하는 기준과 CSS 위치 지정의 기준이 동일해야 합니다.

이미지에 `object-contain`을 적용해 여백이 생기는 경우 실제 이미지 콘텐츠 영역과 부모 요소 크기가 달라질 수 있습니다. 정확한 위치 정합이 필요하면 이미지가 렌더링된 실제 크기와 여백을 고려하거나, 이미지와 오버레이가 같은 비율의 래퍼를 공유하도록 구성합니다.

## 9. AI 결과 상태를 컴포넌트로 구성하기

탐지 결과가 없거나 서버 응답이 늦을 수 있으므로 화면 상태를 나눕니다.

```jsx
function AnalysisPanel({ loading, error, result }) {
  if (loading) {
    return <p className="rounded bg-slate-100 p-4">AI 분석 중입니다.</p>;
  }

  if (error) {
    return <p className="rounded bg-red-50 p-4 text-red-700">{error}</p>;
  }

  if (!result) {
    return <p className="rounded bg-slate-100 p-4">분석할 관측 자료를 선택하세요.</p>;
  }

  return (
    <section className="rounded-lg border bg-white p-4">
      <h2 className="font-semibold">분석 결과</h2>
      <p>모델 버전: {result.model.version}</p>
      <p>예측 건수: {result.predictions.length}</p>
    </section>
  );
}
```

`loading`, `error`, `result` 상태를 기준으로 어떤 화면을 보여줄지 정하면 사용자에게 요청 진행 상황과 오류를 명확하게 전달할 수 있습니다.

## 10. Tailwind CSS와 Chart.js의 역할

Tailwind CSS는 컴포넌트의 간격, 색상, 레이아웃, 반응형 디자인을 빠르게 구성할 때 사용합니다. 프로젝트에 적용된 Tailwind 버전에 맞춰 설정 파일과 스타일 진입점을 사용합니다.

Chart.js는 관측 시각에 따른 수온이나 염분의 변화를 차트로 표시하는 데 사용할 수 있습니다. 오늘은 컴포넌트 구조와 이미지 Bounding Box에 집중하고, 9일차에 해양 시계열 데이터 차트를 본격적으로 구현합니다.

## 실습: 이미지 탐지 결과 화면 만들기

다음 데이터로 `DetectionViewer`를 구성합니다.

```javascript
const sampleResult = {
  imageUrl: "/images/pond-sample.jpg",
  detections: [
    {
      label: "참돔",
      confidence: 0.94,
      box: { x: 0.25, y: 0.18, width: 0.3, height: 0.42 }
    },
    {
      label: "참돔",
      confidence: 0.87,
      box: { x: 0.61, y: 0.36, width: 0.2, height: 0.28 }
    }
  ]
};
```

- 컴포넌트가 이미지 주소와 탐지 배열을 props로 전달받습니다.
- 이미지 위에 각 객체의 Bounding Box를 표시합니다.
- 각 상자에 어종명과 신뢰도를 표시합니다.
- 탐지 결과가 없을 때 빈 상태 안내를 표시합니다.
- Tailwind CSS를 사용해 모바일 화면에서도 읽기 쉬운 간격과 글자 크기를 적용합니다.
- 상자 좌표를 바꾸고 이미지 크기를 조정해 위치가 유지되는지 확인합니다.

## 오늘의 미션

- Props와 State의 차이를 설명합니다.
- State가 바뀔 때 컴포넌트가 다시 렌더링되는 이유를 설명합니다.
- `useEffect`로 API를 호출하고 정리 함수를 사용하는 이유를 설명합니다.
- 정규화 Bounding Box 좌표를 화면 비율로 변환합니다.
- 이미지 위에 여러 탐지 상자와 라벨을 겹쳐 표시합니다.
- 로딩·오류·결과 없음 상태를 구분해 렌더링합니다.

## 핵심 정리

- React 컴포넌트는 재사용할 수 있는 화면 단위입니다.
- Props는 부모가 전달하고 State는 컴포넌트가 관리합니다.
- State가 변경되면 React가 관련 컴포넌트를 다시 렌더링합니다.
- `useEffect`는 API 호출처럼 렌더링과 연결된 부수 효과를 처리합니다.
- Bounding Box는 이미지의 객체 위치를 사각형으로 표시합니다.
- 정규화 좌표는 이미지 표시 크기가 바뀌어도 비율을 유지하는 데 유용합니다.
- Tailwind CSS로 화면 스타일을 구성하고, Chart.js는 이후 시계열 차트에 사용합니다.
- 다음 수업에서는 실시간 수산물 모니터링 대시보드 UI와 Canvas 기반 시각화를 구현합니다.
