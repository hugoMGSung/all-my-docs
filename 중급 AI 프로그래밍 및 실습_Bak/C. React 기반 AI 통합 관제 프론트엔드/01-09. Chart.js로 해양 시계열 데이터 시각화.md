
## 들어가며

앞 장에서는 실시간 모니터링 대시보드의 화면을 구성하고 Canvas API로 객체 탐지 영역을 표시했습니다. 이번 장에서는 양식장과 해양 관측 데이터를 시간 순서로 표시하는 **시계열 차트**를 만듭니다.

수온이나 염분은 한 시점의 값만 보는 것보다 시간에 따라 어떻게 변했는지를 함께 보는 것이 중요합니다. 오늘은 MongoDB API가 반환한 관측 자료를 시간 순으로 정리하고, React와 Chart.js를 사용해 추이 그래프로 표현합니다.

## 1. 시계열 데이터란?

시계열 데이터는 시간 순서에 따라 측정된 값입니다. 해양 관측 자료에서는 관측 시각마다 수온, 염분, 용존 산소량 등이 기록될 수 있습니다.

| 관측 시각 | 수온(℃) | 염분(PSU) |
|---|---:|---:|
| 09:00 | 18.7 | 32.1 |
| 10:00 | 19.1 | 32.0 |
| 11:00 | 19.4 | 32.2 |

시계열 차트의 가로축에는 시간, 세로축에는 측정값을 표시합니다. 이를 통해 값의 상승·하강, 급격한 변화, 결측 구간을 파악할 수 있습니다.

## 2. 차트에 전달할 데이터 구조

Chart.js의 선 그래프에는 보통 라벨 배열과 데이터 배열을 전달합니다.

```javascript
const chartData = {
  labels: ["09:00", "10:00", "11:00"],
  datasets: [
    {
      label: "수온 (℃)",
      data: [18.7, 19.1, 19.4]
    }
  ]
};
```

`labels`는 가로축의 시각이고, `datasets`는 실제로 그릴 하나 이상의 데이터 묶음입니다. 데이터베이스 API의 문서 배열을 이 구조로 변환해 차트에 전달합니다.

## 3. Chart.js와 React 연동 준비하기

React에서는 Chart.js를 감싼 `react-chartjs-2` 컴포넌트를 사용할 수 있습니다. 프론트엔드 프로젝트에서 패키지를 설치합니다.

```bash
npm install chart.js react-chartjs-2
```

간단한 시작을 위해 Chart.js 기능을 자동으로 불러오는 `chart.js/auto`를 사용할 수 있습니다.

```jsx
import Chart from "chart.js/auto";
import { Line } from "react-chartjs-2";
```

`Line` 컴포넌트는 React 화면 안에 Chart.js 선 그래프를 그립니다. 패키지 크기를 최적화하고 싶다면 필요한 차트 컨트롤러, 요소, 축, 플러그인을 직접 등록할 수 있습니다.

## 4. 해양 관측 API 준비하기

프론트엔드는 시간 범위에 해당하는 관측 자료를 API로 요청합니다. API 응답 예시는 다음과 같습니다.

```json
{
  "stationId": "station-032",
  "items": [
    {
      "observedAt": "2026-12-01T00:00:00.000Z",
      "waterTemperature": 18.7,
      "salinity": 32.1
    },
    {
      "observedAt": "2026-12-01T01:00:00.000Z",
      "waterTemperature": 19.1,
      "salinity": 32.0
    }
  ]
}
```

API는 관측 자료를 시간 오름차순으로 반환하는 것이 좋습니다. MongoDB 조회에서 정렬할 수 있습니다.

```javascript
const items = await db
  .collection("marineObservations")
  .find({ stationId })
  .sort({ observedAt: 1 })
  .toArray();
```

데이터가 많으면 기간 조건과 페이지 크기를 정해 필요한 구간만 조회합니다. 예를 들어 최근 24시간의 관측만 반환하도록 제한할 수 있습니다.

```javascript
const from = new Date(request.query.from);
const to = new Date(request.query.to);

const items = await db.collection("marineObservations")
  .find({ stationId, observedAt: { $gte: from, $lt: to } })
  .sort({ observedAt: 1 })
  .toArray();
```

시간 값이 올바른지 확인한 뒤 데이터베이스 조건에 사용해야 합니다. 잘못된 날짜 문자열을 그대로 조회 조건으로 사용하지 않습니다.

## 5. API 자료를 Chart.js 형식으로 변환하기

관측 문서 배열을 차트 라벨과 값 배열로 바꿉니다.

```javascript
function toTemperatureChartData(items) {
  const sortedItems = [...items].sort(
    (a, b) => new Date(a.observedAt) - new Date(b.observedAt)
  );

  return {
    labels: sortedItems.map((item) =>
      new Date(item.observedAt).toLocaleString("ko-KR", {
        month: "2-digit",
        day: "2-digit",
        hour: "2-digit",
        minute: "2-digit"
      })
    ),
    datasets: [
      {
        label: "수온 (℃)",
        data: sortedItems.map((item) => item.waterTemperature ?? null),
        borderColor: "rgb(14, 165, 233)",
        backgroundColor: "rgba(14, 165, 233, 0.15)",
        pointRadius: 3,
        pointHoverRadius: 5,
        tension: 0.25,
        fill: true,
        spanGaps: false
      }
    ]
  };
}
```

원본 배열을 직접 정렬하지 않도록 복사본을 만듭니다. 날짜를 축 라벨로 바꾸고 수온 값을 배열로 전달합니다. 결측된 수온은 0으로 바꾸지 않고 `null`로 두어 실제 측정값과 구분합니다.

이 예제는 날짜 문자열을 범주형 라벨로 표시합니다. 실제 시간 간격을 비례에 맞춰 표시하는 Chart.js `time` 축을 사용하려면 날짜 어댑터도 설치하고 불러와야 합니다.

## 6. React 선 그래프 컴포넌트 만들기

`TemperatureChart.jsx` 파일을 만들고 차트 컴포넌트를 작성합니다.

```jsx
import { Line } from "react-chartjs-2";

const options = {
  responsive: true,
  maintainAspectRatio: false,
  interaction: {
    mode: "index",
    intersect: false
  },
  plugins: {
    legend: {
      display: true,
      position: "top"
    },
    tooltip: {
      enabled: true
    }
  },
  scales: {
    x: {
      title: {
        display: true,
        text: "관측 시각"
      },
      ticks: {
        maxTicksLimit: 8
      }
    },
    y: {
      title: {
        display: true,
        text: "수온 (℃)"
      },
      beginAtZero: false
    }
  }
};

export default function TemperatureChart({ data }) {
  return (
    <div className="h-72 w-full">
      <Line data={data} options={options} aria-label="시간별 수온 추이" />
    </div>
  );
}
```

`responsive: true`는 부모 영역에 맞춰 차트 크기를 조절합니다. `maintainAspectRatio: false`를 지정했으므로 부모 컨테이너의 높이를 CSS로 정합니다. `interaction.mode: "index"`는 같은 시간대의 여러 데이터셋 값을 함께 비교하기 좋습니다.

## 7. 서버 요청 상태와 차트 표시하기

API 요청 중인지, 실패했는지, 데이터가 비어 있는지 화면에서 구분합니다.

```jsx
import { useEffect, useState } from "react";
import TemperatureChart from "./TemperatureChart";

export default function MarineTrendPanel({ stationId }) {
  const [items, setItems] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    const controller = new AbortController();

    async function loadData() {
      setLoading(true);
      setError("");

      try {
        const response = await fetch(
          `http://localhost:3000/api/marine-observations?stationId=${encodeURIComponent(stationId)}`,
          { signal: controller.signal }
        );

        if (!response.ok) {
          throw new Error("해양 관측 자료를 불러오지 못했습니다.");
        }

        const data = await response.json();
        setItems(data.items);
      } catch (requestError) {
        if (requestError.name !== "AbortError") {
          setError(requestError.message);
        }
      } finally {
        if (!controller.signal.aborted) {
          setLoading(false);
        }
      }
    }

    loadData();
    return () => controller.abort();
  }, [stationId]);

  if (loading) return <p>관측 자료를 불러오는 중입니다.</p>;
  if (error) return <p className="text-red-700">{error}</p>;
  if (items.length === 0) return <p>선택한 기간의 관측 자료가 없습니다.</p>;

  const chartData = toTemperatureChartData(items);

  return (
    <section className="rounded-xl border border-slate-200 bg-white p-4 shadow-sm">
      <div className="mb-4">
        <h2 className="text-lg font-semibold">해양 수온 추이</h2>
        <p className="text-sm text-slate-500">관측소 {stationId}</p>
      </div>
      <TemperatureChart data={chartData} />
    </section>
  );
}
```

이 컴포넌트에서 `toTemperatureChartData()`를 사용하려면 같은 파일에 정의하거나 별도 유틸리티 파일에서 import합니다. `stationId`가 바뀌면 효과가 다시 실행되어 해당 관측소 자료를 가져옵니다.

## 8. 시간축을 다룰 때 주의할 점

날짜와 시간을 다룰 때는 정렬과 시간대 표현이 중요합니다.

- 서버와 데이터베이스에는 ISO 8601 시각을 저장합니다.
- 화면에서 한국 시간 등 사용자 지역에 맞게 표현합니다.
- 데이터베이스 조회 결과는 시간 오름차순으로 정렬합니다.
- 측정 간격이 불규칙하면 범주형 라벨 간 간격이 실제 시간 간격과 다를 수 있습니다.
- 시간 간격을 축에 반영하려면 `time` 축과 날짜 어댑터를 사용합니다.
- 결측값은 0으로 오해되지 않도록 `null` 등으로 보존합니다.

범주형 축은 시작하기 쉽지만 측정 시간이 일정하지 않을 때 간격을 동일하게 보이게 합니다. 실제 시간 간격이 분석상 중요하면 시간 축을 사용합니다.

## 9. 여러 측정값 표현하기

수온과 염분처럼 단위와 값의 범위가 다른 자료는 한 그래프에 함께 넣을 때 주의합니다. 단위가 다른 값을 같은 축에 그리면 한 데이터가 거의 평평하게 보여 변화가 잘 드러나지 않을 수 있습니다.

처음에는 수온과 염분을 별도 그래프로 표시하는 방식을 권장합니다. 하나의 그래프에 함께 표시해야 한다면 오른쪽 보조 축을 사용하고 축 제목과 단위를 명확히 표시합니다.

여러 데이터셋을 넣을 때는 각 선의 이름, 색, 단위가 구분되도록 지정합니다.

```javascript
const datasets = [
  {
    label: "수온 (℃)",
    data: items.map((item) => item.waterTemperature ?? null),
    borderColor: "rgb(14, 165, 233)"
  },
  {
    label: "염분 (PSU)",
    data: items.map((item) => item.salinity ?? null),
    borderColor: "rgb(16, 185, 129)"
  }
];
```

위 두 데이터셋을 비교하려면 실제 값 범위를 확인합니다. 필요하면 서로 다른 y축을 구성하거나 차트를 나눕니다.

## 10. 대시보드에서 차트 갱신하기

8일차에 구성한 대시보드의 수온 추이 영역에 `MarineTrendPanel`을 넣습니다. 일정 간격으로 자료를 다시 요청하는 경우 기존 폴링 구조를 재사용할 수 있습니다.

새 자료가 들어오면 React State를 갱신하고, 그에 따라 `Line` 컴포넌트의 `data` prop이 바뀌어 차트가 다시 표시됩니다. 요청 주기를 너무 짧게 설정하면 서버와 브라우저에 불필요한 부하가 생길 수 있습니다.

차트에 표시할 데이터 수가 매우 많다면 전체 자료를 모두 그리기보다 기간을 제한하거나 집계 간격을 늘립니다. 장기간 자료는 시간별·일별 평균, 최솟값, 최댓값 등으로 요약해 전달할 수 있습니다.

## 실습: 해양 시계열 차트 만들기

다음 기능을 완성합니다.

- 관측소 ID와 조회 기간을 이용해 해양 관측 API를 호출합니다.
- 응답 자료를 시간 오름차순으로 정렬합니다.
- 관측 시각과 수온 자료를 Chart.js 형식으로 변환합니다.
- React의 `Line` 컴포넌트로 수온 추이 그래프를 표시합니다.
- 로딩·오류·자료 없음 상태를 표현합니다.
- 결측 구간과 불규칙한 관측 시간 표현의 차이를 확인합니다.
- 필요하면 염분 차트를 별도로 추가하고 단위를 표시합니다.

## 핵심 정리

- 시계열 자료는 시간 순서가 중요한 관측값입니다.
- Chart.js 선 그래프는 시간 라벨과 데이터셋으로 구성할 수 있습니다.
- React에서 `react-chartjs-2`의 `Line` 컴포넌트로 차트를 표시할 수 있습니다.
- 데이터는 시간순으로 정렬하고, 결측값은 실제 0과 구분해야 합니다.
- 불규칙한 시간 간격까지 표현하려면 날짜 어댑터를 사용하는 시간 축을 고려합니다.
- 단위나 값의 범위가 다른 측정값은 별도 차트나 보조 축으로 명확히 표현합니다.
- 다음 수업에서는 데이터 피드백 루프와 모델 버전 관리 등 MLOps 기초를 시작합니다.
